--INPUT REDIRECTION--

< Reads the content of the on the right file, and inputs the text into the command on the left.

EXAMPLE: command_to_run < input_file.txt

<< HEREDOC:
Tells the shell to read text from following lines and put them as input into the command on the right. Stops reading at the delimiter on the right. Surround the delimiter in single quotes so bash does not expand things like variables.

To use input redirection with a specific argument, you need to tell that command to read form stdin instead of a file using a hyphen (-).

EXAMPLE grep hello - < "Hello world Hello world Hello world hello"

--OUTPUT REDIRECTION--

> Replacement redirection. Sends the output of the command on the left into the file on the right. Replaces all the text in the file

EXAMPLE: command > file.txt

>> Append redirection. Sends the output of the command on the left into the file on the right. DOES NOT replace all the text in the file, instead, appends the text to the end of the file
