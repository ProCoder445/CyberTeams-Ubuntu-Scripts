To see if there is a DNS error on your machine (linux), run this cmd: nslookup google.com

If a SERVFAIL error comes up, there is a DNS error, if not RESEARCH!

If so, do sudo vim "/etc/resolv.conf", and add/replace a line with: 

nameserver 127.0.0.53 with nameserver 127.0.0.1:53
127.0.0.1 is the loopback ipv4 address
:53 specifies port 53, the default DNS port

if that does not work, you could do replace the nameserver line with: 
nameserver 1.1.1.1
